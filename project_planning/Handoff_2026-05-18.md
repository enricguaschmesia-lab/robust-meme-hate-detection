## 1. Project in one paragraph

Robust multimodal hateful-meme detection (EE-559 EPFL course
project). OpenCLIP ViT-B/32 (`laion2b_s34b_b79k`) image + text
encoders, frozen, feeding a fusion head over `[t, v, |t−v|, t⊙v] ∈
ℝ^2048`. Image normalisation is *inside* the model (takes [0,1]
pixels) so the same forward graph powers training, consistency-loss
KL, and white-box image attacks. Five training recipes exist on the
`perturbations` branch: `stage1` (clean), `robust-augonly`,
`robust-kl`, `robust-kldrop`, `robust-kllowmed`. Eval surface is 57
single-perturbation cells (8 text × 3 + 11 image × 3) + 12
composite cells (4 types × 3 severities) + FGSM/PGD-10 white-box at
ε ∈ {1,2,4,8}/255 + modality-ablation forward — now replicated on
**dev (n=500)**, **test_seen (n=1000)**, and **test_unseen
(n=2000)**.

## 4. Phase 6 findings (failure-case narrative, the new analytical part)

Extended `scripts/failure_analysis.py` to multi-seed, multi-recipe,
composite-aware. Three sections in the output:

- **Consensus residual hotspots**: 331 dev examples that every recipe
  naturally fails (majority B2 or B3 across seeds). Dominated by
  text-fragile borderline-confident cases and clean-wrong examples
  where the encoder doesn't expose the hateful interpretation.
- **`kldrop` beats `kl` on 34 examples**, *33 / 34 are label=0*. The
  revived image branch carries an anchor against text-attack-induced
  false positives.
- **`kl` beats `kldrop` on 49 examples**, *46 / 49 are label=1*.
  `kl`'s higher clean confidence absorbs the same text attack that
  pushes a `kldrop` borderline-hate prediction across the threshold.

**Strongest deployment-conditional finding of the project**:
false-positive-sensitive contexts (consumer-facing moderation)
should prefer `kldrop`; recall-sensitive contexts (safety-floor
classifier behind human review) should prefer `kl`. Full write-up:
`project_planning/Phase6_Completion_Report.md`.

## 5. Phase 7 findings (held-out test reproduction)

90 cluster jobs (5 recipes × 3 seeds × 2 splits × 3 eval kinds).
All Succeeded; aggregator extended to split-aware output.

### 5.1 What reproduced from dev

- `kldrop` is the worst-cell text robustness winner on every split
  (0.067 dev → 0.074 test_seen → 0.055 test_unseen).
- `kldrop` image-only AUROC exceeds the dedicated baseline on every
  split (0.636 / 0.641 / 0.655 vs baseline 0.628).
- `kl` preserves clean AUROC on test (0.737 → 0.745 → 0.738 vs
  clean baseline 0.742 → 0.747 → 0.738).
- `kldrop` wins 3/4 composite-medium cells on test_seen and
  test_unseen (matches dev).
- In-pool/OOD generalisation: every recipe shows Δ(OOD−in) image
  negative on both test splits, same magnitude as dev. Augmentation
  gains transfer to held-out image attacks.

### 5.2 What changed from dev

- **`kllowmed` has the highest naturalistic-robust count on
  test_unseen** (387 / 2000) — beats `kl` (372.7) by 14. The
  Phase 5c-3 "strict Pareto-dominated" claim does not hold on the
  naturalistic-prior test split. `kllowmed` still loses to `kl` on
  worst-cell text Δ, image-only AUROC, and composite_2text medium.
  Updated framing: borderline case, not a clean negative result.
- **`augonly` becomes more defensible on test** — worst-cell text Δ
  on test_seen (0.083) matches `kl` (0.086). Promote from
  "dominated" to "secondary alternative."
- **Naturalistic-robust percentages drop on test_unseen** (kl 18.6 %
  vs dev 22.3 %, -3.7 pp). The larger pool exposes more text-fragile
  examples; AUROC stays put.

## 7. Cluster artefacts and reproduction

### 7.1 Test-labels staging on cluster (one-shot, done)

```
/scratch/robust-meme-hate-detection/data/test_labels/
  test_seen.jsonl         # 1000 labelled rows
  test_unseen.jsonl       # 2000 labelled rows (img paths rewritten)
  img/  -> /scratch/datasets/hate_meta/img   # symlink for test_seen
  img_test_unseen/        # 2000 real PNGs
```

To rebuild locally + re-stage:

```bash
# Local
PYTHONPATH=src .venv/bin/python3 - <<'PY'
import json
from pathlib import Path
for split, dst in [('seen', '/tmp/test_seen.jsonl'),
                   ('unseen', '/tmp/test_unseen.jsonl')]:
    src = Path(f'data/processed/splits/test_{split}_labels.jsonl')
    rows = [json.loads(l) for l in src.read_text().splitlines() if l.strip()]
    if split == 'unseen':
        for r in rows:
            r['img'] = f"img_test_unseen/{r['id']}.png"
    Path(dst).write_text('\n'.join(json.dumps(r) for r in rows) + '\n')
PY

# Cluster
./cluster/cluster.sh ssh "mkdir -p /mnt/.../scratch-g49/robust-meme-hate-detection/data/test_labels/img_test_unseen
                         ln -sfn /scratch/datasets/hate_meta/img /mnt/.../scratch-g49/.../data/test_labels/img"
scp /tmp/test_seen.jsonl /tmp/test_unseen.jsonl epfl-jumphost:/mnt/.../scratch-g49/.../data/test_labels/
rsync -avzL /tmp/test_unseen_imgs/ epfl-jumphost:/mnt/.../scratch-g49/.../data/test_labels/img_test_unseen/
```

### 7.2 Re-running Phase 7 (the 90 jobs)

`/tmp/submit_phase7.sh` (in this session's tmp dir) is the canonical
submission script. Key gotchas it bakes in:

- Job names use **hyphenated split tags** (`test-seen` / `test-unseen`);
  Run:AI rejects underscores. The `--split` CLI arg keeps the
  underscored form (`test_seen` / `test_unseen`).
- The `kldrop` recipe maps to **config `configs/stage1_robust_kl_drop.yaml`**
  (underscore in `kl_drop`), not `configs/stage1_robust_kldrop.yaml`.
- Each `submit-cmd` call delete-then-recreates the job (idempotent).
