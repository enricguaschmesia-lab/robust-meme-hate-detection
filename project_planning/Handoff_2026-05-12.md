## 1. Project in one paragraph

EE-559 (EPFL) course project on **adversarial robustness of multimodal hateful
meme detectors**. We train a frozen-encoder OpenCLIP ViT-B/32 dual-encoder
classifier on the Hateful Memes dataset, attack it with FGSM/PGD and a
naturalistic perturbation suite (8 text × 10 image attacks × 3 severities),
and will compare clean training to a robust variant that combines perturbation
augmentation with a KL consistency loss. The final deliverable is a report and
poster grounded in measurable robustness metrics, not a SOTA classifier.

- Cluster: `/scratch/robust-meme-hate-detection/experiments/inspect-perturb-20260512-211209-a4852b5/`

A copy-pasteable review protocol is in `README.md` under
"Phase 3 label-preservation review". When the user completes the review:

1. Save `review/sample.csv` and `review/results.csv` under
   `project_planning/phase3_label_review/`.
2. Append a short summary to `Phase1-2_Completion_Report.md` (or open
   `Phase3_Completion_Report.md`) with the per-cell tally and any
   flagged cells (low/medium severity with > ~5 % drift).
3. Phase 3 then closes.

Failure modes to expect at high severity (do not gate Phase 3 on these):

- `char_deletion high`, `censoring high` — may erase the hateful token.
- `blur high`, `compression high`, `gaussian_noise high` — may erase
  meme caption.
- `occlusion high` — may cover the depicted person/symbol.

## 6. Phase 4 — recommended first action

Run the benchmark against the existing checkpoints (no new training needed):

```bash
for seed in 0 1 2; do
  ./cluster/cluster.sh submit-cmd "perturbed-stage1-seed$seed" -- \
    /home/guasch/robust-meme-hate-detection/scripts/cluster_entrypoint.sh \
    robust_meme_hate_detection.eval.run_perturbed \
      --ckpt "/scratch/robust-meme-hate-detection/experiments/stage1-seed$seed-*/ckpt/best.pt" \
      --config configs/stage1.yaml \
      --out "/scratch/robust-meme-hate-detection/experiments/perturbed-stage1-seed$seed"
done

# Then for the unimodal baselines (single seed each):
./cluster/cluster.sh submit-cmd perturbed-baseline-text -- \
    /home/guasch/.../cluster_entrypoint.sh \
    robust_meme_hate_detection.eval.run_perturbed \
      --ckpt /scratch/.../baseline-text-seed0/ckpt/best.pt \
      --config configs/stage1_text.yaml \
      --attacks text \
      --out /scratch/.../perturbed-baseline-text
# Symmetric for image baseline, restricted to --attacks image.
```

`run_perturbed.py` writes one `perturbed_eval.json` per checkpoint with
per-cell metrics, robustness gap, ASR, and per-example clean+attacked
probabilities. Expected wall-clock: ~15–30 min/seed (54 cells × ~500 examples
through the dual encoders, bf16, batch 64).

Output schema is documented inline in `eval/run_perturbed.py`. Downstream
plots/tables need a small aggregation script that has not been written yet —
that's the second Phase-4 task.
